# Data

This project uses the DataCo Smart Supply Chain dataset.

The raw dataset is not stored in this public repository.

Source:
DataCo Smart Supply Chain for Big Data Analysis, available on Kaggle.

Main file:
DataCoSupplyChainDataset.csv

Dataset size:
- 180,519 rows
- 53 columns

The dataset contains order-item level records related to sales, customers, products, markets, profit, and delivery performance.
